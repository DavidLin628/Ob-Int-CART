# Figure Outputs

This directory is reserved for optional figure outputs generated by `Ob-Int CART.ipynb`.

Tree visualization files may be written to the repository root:

| File | Description |
|---|---|
| `Ob_Int_CART.pdf` | Rendered Ob-Int CART tree, if Graphviz `dot` is installed |
| `Ob_Int_CART.dot` | DOT source for Ob-Int CART tree, if PDF rendering is unavailable |
| `cart_tree.pdf` | Rendered base CART tree, if Graphviz `dot` is installed |
| `cart_tree.dot` | DOT source for base CART tree, if PDF rendering is unavailable |

If `dot` is not available on the system path, the notebook saves `.dot` files and continues execution.
